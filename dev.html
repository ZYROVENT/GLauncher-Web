GLauncher StyleSheet & Script

GSS es un lenguaje híbrido y declarativo diseñado específicamente para la personalización de GLauncher. Combina la lógica de Luau (Roblox) con la potencia de CSS moderno y spawning seguro de componentes interactivos.

Eres un desarrollador experto en GSS (GLauncher StyleSheet & Script v7.0), el lenguaje de estilos y scripting seguro de GLauncher.
Tu tarea es escribir código .gss válido, limpio y creativo para temas visuales y componentes interactivos del launcher.

### REGLAS FUNDAMENTALES DE GSS v7.0:
1. SINTAXIS Y VARIABLES (Estilo Luau / Roblox):
   - Variables: `local nombre_var = "valor"` o `contador = 10`
   - Comentarios: `-- comentario` o `# comentario`
   - Tipos: String, Number, Boolean (`true`, `false`)
   - Concatenación y Operaciones: Soporta `+`, `-`, `*`, `/`, `%` y `"texto " + variable`
   - Condicionales: `if condicion then ... else ... end` (operadores: `==`, `~=`, `!=`, `<`, `>`, `and`, `or`, `not`)
   - Bucles: `for i = 1, 5, 1 do ... end` y `while condicion do ... end`
   - Temporizador: `task.wait(segundos)`
   - Logs y Notificaciones: `print("mensaje")` y `notify("mensaje emergente")`
   - Sonidos locales: `play sound "assets/sounds/click.ogg"`

2. SELECTORES SEMÁNTICOS PREDEFINIDOS (Bloques terminados en `end`):
   - `navbar` / `barra_navegacion`: Barra de navegación inferior
   - `navbar_btn` / `botones_navbar`: Botones de navegación
   - `navbar_btn_active`: Botón de navegación activo o hover
   - `button` / `botones`: Botones primarios del launcher
   - `button_secondary`: Botones secundarios
   - `card` / `tarjetas`: Tarjetas de mods, servidores y versiones
   - `mini_player` / `mini_reproductor`: Reproductor flotante GMusic
   - `modal` / `ventana_flotante`: Ventanas modales y paneles
   - `campos_texto` / `input`: Campos de texto y búsqueda
   - `scrollbar` / `barra_desplazamiento`: Scrollbar personalizada
   - Selectores CSS libres: `style ".mi-clase" { ... }`

3. ALIAS AUTOMÁTICOS EN ESPAÑOL:
   - `fondo:` -> `background:`
   - `redondeado:` o `esquinas:` -> `border-radius:`
   - `brillo:` o `sombra:` -> `box-shadow:`
   - `letra:` o `texto_color:` -> `color:`
   - `desenfoque: 20px` -> `backdrop-filter: blur(20px)`
   - `borde:` -> `border:`
   - `relleno:` -> `padding:`, `margen:` -> `margin:`

4. SPAWNING DE COMPONENTES INTERACTIVOS (`spawn  in ""`):
   - Tipos: `button`, `card`, `label`, `icon`, `badge`
   - Targets seguros: `.card`, `.view-content`, `header`, `.modal-content` (NUNCA en body/html)
   - Propiedades del spawn:
     * `text: "Texto"`
     * `icon: "fa-solid fa-bolt"`
     * `move: "bottom-right"` (o `top-right`, `bottom-left`, `top-left`, `center`)
     * `move_x: "10px"`, `move_y: "10px"`
     * `sound: "assets/sounds/click.ogg"`
     * `on_click: "notify:¡Mensaje al hacer clic!"`
     * Estilos inline: `fondo: "..."`, `redondeado: "..."`, `brillo: "..."`
     * Cierre: `end`

5. SEGURIDAD Y SANDBOX:
   - Solo recursos multimedia locales (`.png`, `.jpg`, `.mp4`, `.ogg`, `.wav`, etc.).
   - PROHIBIDO enlaces http/https externos o comandos ejecutables (`.bat`, `.exe`, `.sh`).

1. Introducción y Filosofía

GSS permite a creadores de temas y desarrolladores personalizar la interfaz visual de GLauncher, disparar efectos de sonido reactivos y añadir componentes interactivos sin necesidad de programar en JavaScript complejo ni comprometer la seguridad del launcher.

Arquitectura Segura y Sandbox

A diferencia de otros motores que usan eval() o Function(), GSS v7.0 incluye un evaluador léxico seguro (AST) aislado:

  • No ejecuta comandos del sistema operativo (.bat, .cmd, PowerShell, Bash).
  • Bloquea protocolos externos inseguros (http://, ftp://) y conexiones de red no autorizadas.
  • Solo admite formatos multimedia permitidos: .png, .jpg, .webp, .gif, .svg, .mp3, .ogg, .wav.

2. Variables y Sintaxis de Luau

Las variables se declaran con la palabra clave opcional local o asignación directa. Soportan cadenas de texto, números enteros, decimales y booleanos.

GSS Variables 
-- Declaración de variables globales y locales
local tema_principal = "#00f0ff"
local brillo_neon = "0 0 20px rgba(0, 240, 255, 0.6)"
local radio_esquinas = "14px"
local activar_alerta = true
local iteraciones = 3

Expresiones Matemáticas y Lógicas

El motor soporta operadores aritméticos (+, -, *, /, %), comparadores de Luau (==, ~=, !=, <, >, <=, >=) y operadores lógicos (and, or, not).

3. Control de Flujo (Bucles y Condicionales)

Bucle for numérico y task.wait

GSS For Loop 
-- for variable = inicio, fin, paso do ... end
for i = 1, 3, 1 do
    print("Generando pulso neon #" + i)
    play sound "assets/sounds/click.ogg"
    task.wait(0.2)
end

6. Uso en GLauncher y CLI

Los archivos .gss se cargan en GLauncher desde la sección Temas → Mis Temas, o bien desde la CLI con el siguiente comando:

CLI — GLauncher 
# Aplicar un tema .gss directamente desde la terminal
glauncher theme apply ./mi-tema.gss

# Ver el tema activo
glauncher theme status

# Resetear al tema por defecto
glauncher theme reset

# Validar sintaxis sin aplicar
glauncher theme lint ./mi-tema.gss
Los archivos .gss se guardan en %APPDATA%/GLauncher/themes/ en Windows y en ~/.config/glauncher/themes/ en Linux/macOS. GLauncher los recarga automáticamente al guardar sin reiniciar.

task.wait y Control de Tiempos

task.wait(segundos) pausa la ejecución del script GSS durante el tiempo especificado, igual que en Luau/Roblox. Es útil para animaciones secuenciales, efectos de entrada y notificaciones diferidas.

GSS — task.wait 
-- Efecto de arranque escalonado con esperas
print("Iniciando sistema...")
task.wait(0.5)

notify("🟢 GSS Engine cargado")
task.wait(1.0)

notify("🎨 Aplicando estilos...")
task.wait(0.8)

-- Bucle con espera para pulso visual
for i = 1, 3, 1 do
    play sound "assets/sounds/ping.ogg"
    task.wait(0.3)
end

notify("✅ ¡Tema activado con éxito!")
Límite de seguridad: El valor máximo de task.wait es 10.0 segundos. Valores mayores son truncados automáticamente por el sandbox. El tiempo mínimo es 0.05 segundos.

7. Audio Reactivo

GSS permite reproducir sonidos locales en respuesta a eventos del usuario. Los formatos permitidos son .ogg, .mp3 y .wav. Los sonidos deben estar en la carpeta de assets del tema.

GSS — Audio 
-- Reproducir un sonido al iniciar el tema
play sound "assets/sounds/startup.ogg"

-- Audio combinado con condicional
local modo_noche = true

if modo_noche == true then
    play sound "assets/sounds/night_mode.ogg"
    notify("🌙 Modo Noche Activado")
else
    play sound "assets/sounds/day_mode.wav"
    notify("☀️ Modo Día Activado")
end

-- Audio secuencial con task.wait
for i = 1, 2, 1 do
    play sound "assets/sounds/beep.ogg"
    task.wait(0.25)
end
play sound "assets/sounds/confirm.ogg"
Formato Compatibilidad Uso recomendado
.ogg ✅ Preferido Efectos de sonido cortos, clics, notificaciones
.mp3 ✅ Soportado Música de fondo de baja duración
.wav ✅ Soportado Efectos sin compresión, alta calidad
.mp4 / .webm 🔒 Solo imagen No se reproduce audio de video

9. Selectores CSS Nativos

Además de los selectores semánticos predefinidos, GSS permite apuntar a cualquier elemento del launcher usando la instrucción style ".selector" con CSS puro.

GSS — CSS Nativo 
-- Selectores CSS libres con style ".clase"
style ".mod-card:hover" {
    transform: translateY(-4px);
    box-shadow: 0 12px 30px rgba(0, 240, 255, 0.3);
    border-color: #00f0ff;
}

style ".version-badge" {
    background: linear-gradient(135deg, #4ade80, #22c55e);
    color: #000;
    font-weight: 700;
    border-radius: 999px;
    padding: 2px 10px;
    font-size: 0.75rem;
}

style ".play-btn" {
    background: linear-gradient(135deg, #00f0ff, #0070ff);
    border: none;
    border-radius: 14px;
    color: #fff;
    font-weight: 800;
    font-size: 1.1rem;
    box-shadow: 0 0 30px rgba(0, 240, 255, 0.5);
}

style ":root" {
    --primary: #00f0ff;
    --accent: #ff007f;
    --bg-main: #090d0a;
}
Los bloques style ".selector" { } usan llaves { } en vez de end. Dentro de ellos solo se admite CSS estándar — no se puede mezclar con lógica Luau.

11. Eventos y Notificaciones

GSS soporta notificaciones emergentes con notify() y reacciones a clics en componentes spawneados mediante la propiedad on_click.

GSS — Eventos 
-- Notificaciones directas desde el script
notify("🎨 Tema cargado correctamente")
task.wait(2.0)
notify("⚡ Efectos activados")

-- Notificación condicional
local primera_vez = true

if primera_vez == true then
    notify("👋 ¡Bienvenido! Este es tu primer tema GSS")
    play sound "assets/sounds/welcome.ogg"
end

-- on_click: soporta el prefijo "notify:" para disparar una notificación
spawn button in ".card":
